# ⏱ Time Calc v2.2

HH:MM:SS 形式の時間を加算・減算できる Web アプリ。  
放送局のタイムキーパーや動画編集者、タスク管理向けに設計されています。

🔗 **[Live Demo](https://frente-byte0038.github.io/Time-calculatorNya/)**

---

## 機能

- **複数行の時間計算** — A〜J の最大 10 行で加算・減算を同時に処理
- **符号切替** — 各行の `+` / `−` ボタンで加減算を切り替え
- **2つのモード**
  - `時間計算` — 入力した時間の合計を計算（経過時間など）
  - `実時間` — 基準時刻に時間を加減算（24時間 mod で正規化）
- **キーパッド入力** — 画面上のボタンで数字・演算を入力
- **キーボードショートカット**

  | キー | 動作 |
  |---|---|
  | `0`〜`9` | 数字入力 |
  | `+` / `-` | 符号切替 |
  | `Enter` / `Tab` | 次の行へ移動 |
  | `Shift+Tab` | 前の行へ移動 |
  | `Backspace` | 1桁削除 |
  | `C` | 現在行クリア（空なら全クリア） |
  | `A`〜`J` | 対応する行へジャンプ |

- **→A ボタン** — 計算結果を行 A にコピーして連続計算が可能
- **式の表示** — 複数行入力時に計算式をサブ表示
- **分換算表示** — 合計を「〇〇分」でも表示
- **テーマ切替** — ダーク / ライトモードをトグル（設定を記憶）
- **PWA 対応** — ホーム画面へのインストール・オフライン動作に対応
- **レスポンシブ対応** — 画面幅に応じてフォントサイズ・ボタン・余白が自動調整（320px〜）

---

## 使い方

1. ブラウザで [Live Demo](https://frente-byte0038.github.io/Time-calculatorNya/) を開く
2. キーパッドまたはキーボードで時間を入力（例：`1`, `3`, `0`, `0`, `0` → `00:01:30:00`... → `01:30:00`）
3. `＋ 行を追加` で行を増やし、各行に時間と符号（+/−）を設定
4. メインディスプレイに合計が即時表示される
